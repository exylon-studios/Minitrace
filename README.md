# Minitrace

A small, hand-written ray tracer in C, based on the wonderful [Ray Tracing in One Weekend](https://raytracing.github.io/) series. It reads a simple scene data from a custom text-based .sdn file and renders a PPM output.

Originally, I wrote this in military without internet using an outdated copy of Dev C++.
